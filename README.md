# exact-parity-lab

**承诺：对 3 个封闭网格、2,106 个点做内外判定，精确有理数射线奇偶 0 错、0 个不确定；同样查询下教科书 float 射线（Möller–Trumbore + ε=1e-12）118 个判错（5.60%），同时最近距离查询比独立暴力 oracle 快 **47.6×**（8.09 µs vs 385.41 µs/查询，703 查询）。**

Upstream: none

这是一个可在 node 里数字复算的「点 → 封闭网格」查询核心：一次 BVH 遍历同时给出最近点距离，以及**不带 epsilon** 的内外号。精确号用 BigInt 把每个 double 展开成二进制有理数 `m·2^e`，`orient3d`、射线-三角求交、三角形内判定全部是整数/有理数运算；射线若恰好擦到边或顶点，判定为 degenerate 并换一条通用方向重试，绝不猜。

## 怎么跑（一条命令）

```bash
node tools/gen-sample.mjs && node bench/verify.mjs && node bench/bench.mjs
```

- `verify.mjs` 退出码 0 才代表全部断言通过（当前 10/10）。
- `bench.mjs` 写 `bench/result.json`（cold + 5 样本，median/p95/stddev）。
- 页面：`python3 -m http.server 4173` 后开 `http://localhost:4173`（three.js r0.170.0，CDN importmap，版本写死）。
- 只需要 Node ≥ 20，无依赖、无 `npm install`。

## 本轮创新

**首次把「精确有理数谓词」用在浏览器可交互的点-网格查询闭环里，并且浏览器与 node 跑的是同一个 `src/core.mjs`。** 台账里的 `surface-intersect-lab` / `mesh-selfint-lab` 都是 float 谓词 + BVH 的检测；`pointpick-lab` 是射线拾取；没有一个工具把**内外号**做到无 epsilon、并把「射线擦边时换向重试」的 138 次退化作为可复算数字暴露出来。新在：符号判定完全脱离浮点（BigInt 二进制有理数），退化不猜、而是可判地重试；页面上的绿/橙/紫点与 `bench/verify.mjs` 的 2,106/2,106 来自同一份 core。

## 已知限制

- **精确的是「被表示的那组 double」构成的网格**，不是原始设计曲面；细分误差是另一回事。
- 查询点若恰好落在面上、或三条通用射线**都**擦到边/顶点，返回 `inconclusive`。本语料 0 个；轴对齐查询里 138 条被重试，这是设计行为不是失败。
- **float64 在近表面偏移（δ ≥ 1e-11·diag）上也是 0 错**：本仓库测到的 float 失败全部来自轴对齐射线的边/顶点退化，不要把结论读成「float 做不了近表面」。换向抖动（jitter）通常也能修掉这些错误；exact 的收益是**确定性、无 ε、可判重试**，不是唯一能修。
- 绝对阈值披露：距离容差 `1e-12·diag`；射线长度 `4·diag`；近表面 δ ∈ {1e-3, 1e-6, 1e-9, 1e-11}·diag；尺度只测到 1e-12…1e6，更小尺度会进入次正规数，未测。
- 语料是 3 个解析图元（sphere/box/torus）生成的 10,352 个三角形，**不是扫描资产**；真实网格的薄片、非流形、孔洞未覆盖。
- 47.6× 是在本语料（1,200–5,184 三角）上的 703 查询测得；BVH 加速比随网格规模和查询分布变化。独立复算时 brute 路径出现过一次环境抖动（73.6×、645.6 µs/查询），第二次恢复 47.0×；结构性计数（2,106 / 118 / 138）两次完全一致，timing 以发布版 result.json 为准。
- 页面依赖公网 CDN 加载 three.js（版本固定 0.170.0），离线打不开；核心与证据不需要浏览器。
